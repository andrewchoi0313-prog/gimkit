# Lava Leap 🌋

A 10-stage Roblox obby over a sea of lava. The whole course is built by a script when the game starts, so there's nothing to build by hand.

## Stages

| # | Stage | What to do |
| --- | --- | --- |
| 1 | Stepping Stones | Hop across small floating stones. |
| 2 | Lava Stripes | Jump over red stripes that keep getting wider. |
| 3 | Staircase | Zig-zag up seven floating steps. |
| 4 | Truss Climb | Climb a 24-stud truss tower. |
| 5 | Balance Beams | Walk thin, zig-zagging beams. |
| 6 | Vanishing Tiles | Keep moving: tiles fade away after you touch them. |
| 7 | Moving Platforms | Time your jumps across sliding platforms. |
| 8 | Conveyor Hurdles | Fight a backwards conveyor while jumping red hurdles. |
| 9 | Jump Pads | Green pads launch you up two tall steps. |
| 10 | The Sweeper | Jump a spinning red bar to cross a round platform. |

Touching anything red, or the lava, sends you back to your last checkpoint. Checkpoints turn green when you reach them. The screen shows your stage, a run timer, your best time, and a **Restart run** button. The leaderboard shows Stage and Wins.

## Play it in Roblox Studio

**Option A: open the place file.** Download `LavaLeap.rbxlx`, then in Roblox Studio choose **File → Open from File** and pick it. Press **Play**.

**Option B: paste the scripts into any place.**

1. Create a new place from the **Baseplate** template.
2. In the Explorer, right-click **ServerScriptService → Insert Object → Script**. Name it `LavaLeapServer` and paste in `src/server/LavaLeapServer.server.luau`.
3. Open **StarterPlayer**, right-click **StarterPlayerScripts → Insert Object → LocalScript**. Name it `LavaLeapClient` and paste in `src/client/LavaLeapClient.client.luau`.
4. Press **Play**.

The course appears when the game runs, not in edit mode. The server script removes the template's `Baseplate` and `SpawnLocation`, because you'd land on them instead of the lava.

**To publish:** **File → Publish to Roblox**, then set the game to Public in its settings on the Creator Dashboard when you're ready.

**Saving progress:** stage, wins and best time save automatically in a published game. To test saving inside Studio, turn on **Game Settings → Security → Enable Studio Access to API Services**. Without it the game still works; progress just isn't kept between sessions.

## Change the course

Everything lives in the `STAGES` list in `LavaLeapServer.server.luau`. Each stage has a `name`, a `color`, and a `build` function. A `build` function gets the point where its checkpoint ends and returns the point where the next checkpoint should start. Add, remove, or reorder entries and the checkpoints, signs and stage count update on their own.

Helpers you can use in a stage: `platform`, `block`, `makeHazard` (red kill brick), `makeVanishing`, `makeMover`, and `makeSweeper`. To add a jump pad, tag a part `LavaLeapJumpPad`.

## Rebuild the place file

The place file is generated by [Rojo](https://rojo.space) from `default.project.json`:

```sh
rojo build default.project.json -o LavaLeap.rbxlx
```

With Rojo's Studio plugin, `rojo serve` live-syncs the scripts into Studio as you edit them.
